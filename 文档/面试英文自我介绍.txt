The second project is WVP Copilot — an LLM-based AI Agent for drone control. Users can simply type natural language commands like "Fly to Lujiazui, zoom to 7x, take a photo, then return home," and the Agent handles intent understanding, task planning, and execution. I built the Python Agent orchestration layer using LangChain and LangGraph, integrated 16 custom tool functions and 15 Amap MCP tools, and developed the SSE streaming frontend for real-time observability. The hardest parts were: ensuring real-time precision — we replaced LLM temporal decision-making with a LangGraph state machine for orbit flight to eliminate 3-9 meter photo drift caused by inference latency; and safety isolation — the emergency stop goes through a separate MQTT hardware channel bypassing the LLM entirely.
