# 外呼智能巡检与话术优化体系

## 项目背景：
面向金融电销与催收场景，针对外呼机器人存在的意图识别偏差、话术缺失与质检成本高等问题，设计并落地基于大模型的自动巡检与优化体系，构建“问题识别—自动修复—数据反馈”闭环，提升外呼质量与巡检效率。

## 业务价值：
日均巡检2W+cases，场景覆盖80%+，人工数量由4人全量巡检降至1人抽检复核，节省人力成本50w/年。

## 项目模块：
### 话术匹配评价模型（任务建模 + CoT蒸馏）

#### 问题重构：
针对金融外呼中话术适配度与用户诉求、业务节点与流程策略共同约束，将任务重构建模为“诉求识别—业务知识判断—结论推断”的三阶段推理链，解决原先方案难以通过语义匹配稳定判定的问题。

#### CoT蒸馏数据生产pipeline：
基于拒绝采样范式，以 DeepSeek-R1 为教师模型进行 10 次 rollout 生成多样化推理链候选集，通过 pass@10 进行不确定性量化与质量筛选，引入 **Corrector-LLM** 对冲突样本进行推理链修正，并经验证收敛标准，最终构建 8K 条高一致性推理链数据集。

#### 微调与结果：
采用 LoRA/FFT 进行微调，综合评估后选择 Qwen-3-14B 作为学生模型，最终上线模型 **Accuracy 达 89.85%**（较原方案提升 15.2%），问题样本 **Recall 达 93.44%**，实现业务推理能力的高效迁移。

## 项目模块：
### 问题优化智能体（RAG + 多阶段 Workflow Agent）

#### 设计思路&定位：
针对话术匹配模型仅能检测问题、无法自动修复，基于 RAG 构建多阶段优化 Agent，实现异常 case 自动纠正与话术补全，形成检测—修复闭环。

#### RAG知识库构建：
将业务 QA 与话术数据设计成“语义对话库 + FAQ 全局库”双库结构，并基于业务场景与语义节点设计多级业务 metadata，实现检索前置过滤，并利用节点层级关系约束检索范围，**误召回率相对降低 26.4%**。

#### 检索&过滤模块：
采用 Milvus 构建检索向量库（Qwen-3-14B embedding），通过 **Query Expansion** 与 **HyDE** 提升召回覆盖，并结合标签与 metadata 分层检索；引入 **LLM-based Filtering** 对候选结果精准过滤，**Recall@10 提升至 93%**。

#### 闭环优化：
基于 Human-in-the-Loop 反馈机制，对 badcase 分析进行数据回流，并对检索、prompt 及知识注入模块进行定向优化，实现问题识别准确率 91.87%、修复意图准确率 95.17%，累计补全缺失话术 500+。

# 语义树配置与策略优化智能体

## 项目描述：
运营基础平台 2.0 升级方案，面向外呼语义树配置场景，构建自然语言驱动的结构化编辑系统，通过多智能体实现配置自动化与数据驱动优化，推动策略向“可控生成 + 持续优化”的智能体平台演进。

#### Multi-Agent架构设计（LangGraph）：
- **主 Agent** 基于 **Plan-and-Execute + ReAct** 模式，通过 NLI→Action 建模将配置需求结构化，负责统一决策与操作执行；策略优化 Agent(Thinking模式)基于节点数据分析生成结构调整方案（如节点合并/拆分）；以 MCP 接入组件话术生成 Agent 提供话术生成优化能力。

#### 原子化编辑与执行后校验机制：
将语义树编辑抽象为 add/delete/replace 原子操作，Agent 仅输出变更节点/边的最优 **patch级指令**，实现局部可控更新（**token ↓ 80%**，错误率 ↓ 65%**）；执行阶段将生成的修改应用到目标语义树并进行结构一致性校验，失败时返回错误驱动模型自修正，**一次交付成功率提升至 90.15%**。

#### 结构化上下文管理（Context System）：
构建三层上下文体系，会话层仅保留用户输入与操作摘要（解耦执行细节）；任务层按需加载 Mermaid 子树拓扑以压缩上下文并避免污染；记忆层增量总结用户配置偏好并结构化存储为 **Long-term Memory**，实现跨会话个性化配置。

# 项目一：基于 Multi-Agent 的自动化研究助手  
**项目描述与工程实现：**

- 全链路可观测性：深度集成 Langfuse 实现 Trace 级监控，精细化追踪各 Agent 节点的输入输出、Token 消耗及工具调用（Function Calling）耗时，为系统延迟优化提供数据支撑。  
- 会话持久化与高可用：开发基于 Redis 的会话记忆模块，支持上下文状态检查点（Checkpoint）存储与中断恢复。优化异常处理逻辑，在外部大模型 API 熔断时无缝降级至本地 SimpleAgents 兜底。  

# 项目二：企业级 RAG 混合检索生成引擎  
**项目描述与算法优化：**  
- 级联检索架构：构建面向非结构化文档的高性能 RAG 问答引擎。利用 LlamaIndex 与 Milvus 向量数据库构建基础的高维稠密检索（Dense Retrieval）。  
- 精准重排机制：设计了支持多后端的即插即用重排模块（Reranker）。在最终召回阶段，实现并对比了 LLM Reranker（基于提示词的高精度重排）与 BGE-Reranker（本地轻量交叉编码器）两套方案。在保障 Top-K 召回准确率的同时，使系统能够根据业务对“低延迟”或“高精度”的不同诉求进行热切换。  
- 防幻觉与评测：系统引入低置信度拒答提示词策略与文献引用溯源链。线下利用 RAGAS 自动化探索 Chunk Size 与检索超参，使输出忠实度（Faithfulness）跃升 30。线上通过 LangFuse 追踪全链路时延、Token 消耗及检索分值，实现检索质量的可视化闭环。  

# 项目三：基于深度学习的皮肤病变识别算法研究
