1. 参与数据采集及数字化处理系统的后端开发，面向公司多服务数据分散、缺少统一数据基建的现状，建设从数据接入、清洗、审核到同步入仓的全流程数据处理链路。

2. 针对多数据源场景下 Controller 频繁手动实例化导致的代码重复问题，利用 JDK 动态代理 + 反射封装统一代理层，将实例化与横切逻辑集中管理，实现模块解耦，降低后续开发成本。

3. 设计自定义注解 + AOP 切面的冗余字段自动处理方案（@RedundantField + @IgnoreRedundant），请求进入 Controller 前自动清理冗余字段，消除每个接口手工 set null 的重复代码。

4. 建设同步过程的数字化监控模块，实时展示各链路同步状态、业务量及审核异常；开发预警机制，数据量或失败次数超阈值时自动触发告警推送。

5. 监控看板采用定时缓存预热策略，解决大量同步数据加载慢的问题，提升看板接口响应速度。
