\cvproject{项目一：无人机管理云平台}{}{2025/04 -- 2026/03}{%
    \cvtech{Java、SpringBoot、Redis、MySQL、MyBatis(Plus)、WebSocket、MQTT、Vue、JavaScript、TypeScript、Cesium}
    \cvlabeled{项目概述}{在公司物联网平台基础上，利用自组网超远距离（>20km）优势新增无人机接入模块，实现空地一体化指挥调度。}
    \cvlabeled{项目实现}{%
        \begin{itemize}
            \item \textbf{无人机接入与设备管理}：将无人机纳入现有设备管理体系并复用区域权限；Redis 维护在线状态（60s TTL 心跳续期）与离线原因，区分主动下线与异常断连；监听 Spring 启动就绪事件，服务启动后经 MQTT 向硬件逐台下发重启指令，重启后自动恢复在线，无需人工值守。
            \item \textbf{飞行控制与相机系统}：实现一键起飞、指点飞行、环绕飞行、返航、急停及变焦、拍照、录像、云台重置等飞行与相机指令；前期前端直连 MQTT 快速验证，后期将关键相机指令与航线任务迁至后端，并补充限高校验与降落确认，降低超限与误操作风险。

        \end{itemize}

\cvproject{项目二：WVP Copilot --- 基于 LLM 的无人机 AI Agent 智能体}{}{2025/11 -- 2026/03}{%
    \cvtech{Python、LangChain、LangGraph、SSE、MCP、FastAPI、DeepSeek API、Redis}
    \cvlabeled{项目概述}{面向消防应急指挥的无人机 Copilot：把自然语言需求（如“飞到陆家嘴，变焦 7x 拍照，返航”）拆解为指令序列并编排执行；采用 Python（Agent 编排层）+ Java（设备控制层）两层架构，通过 REST 解耦。}
    \cvlabeled{项目实现}{%
        \begin{itemize}
            \item \textbf{异步状态同步与故障兜底}：工具函数内每秒轮询 Redis 任务状态，超时阈值按预估飞行时间动态设定；超时不直接判失败，先查 OSD 位置兜底（< 5m 判到达、无位移判硬件故障、仍在移动则延长等待），中间进度只推前端，LLM 只取最终状态。
            \item \textbf{任务链级联阻断与安全隔离}：Plan-Confirm-Execute 三段式，计划经用户确认卡片审核后逐步执行，任一步返回失败或急停即中断后续；飞行、返航在工具层内置确认钩子；急停走独立 MQTT 通道并同步中断 SSE 连接，不经过 Agent 与 LLM。
            \item \textbf{状态机替代 LLM 时序决策}：用 LangGraph 条件子图建模环绕飞行——enter\_orbit \thickarrow{} orbit\_step（按角度步进拍照，$\ge 360^\circ$ 条件边退出）\thickarrow{} exit\_orbit，拍照时机由图状态转移决定，规避 LLM 推理延迟在 3m/s 下造成的 3-9 米偏移；线性主链路仍用 AgentExecutor。
        \end{itemize}
    }
}
