    \cvlabeled{背景与诉求}{平台原有能力集中于地面 Mesh 设备管理，缺乏对无人机的统一接入与远程控制能力，无法满足消防场景下超视距视频回传与飞行控制需求。公司自组网具备超远距离传输优势，需基于此建设无人机模块，实现空地一体化指挥调度。}

            \item \textbf{飞行控制与相机操作}：完成一键起飞、指点飞行、环绕飞行、航线飞行、返航、急停等飞行指令，以及变焦、拍照、录像、模式切换、云台重置、框选变焦、AIM 瞄准等相机负载指令的功能实现。前期大部分指令由前端通过 MQTT 与硬件直接通信以快速验证功能，后期将部分相机指令（框选变焦、AIM）迁移至后端统一处理，提高可维护性。后端增加飞行安全校验逻辑：起飞/返航/目标高度 vs 系统限高对比校验、降落确认与取消。

            \item \textbf{实时视频点播服务}：集成 ZLM 流媒体服务器，搭建无人机视频流 \ \faArrowRight\  ZLM 拉流转发 \ \faArrowRight\  前端多种播放格式（H5\slash WebRTC\slash Jessibuca）的完整链路。基于 Spring DeferredResult 实现异步点播：前端发起 HTTP 请求后，后端立即释放 Tomcat 线程，异步等待 ZLM 推流就绪后再通过回调返回播放地址，避免点播等待期间占用线程资源。设计 Redis 引用计数策略：每个视频流维护观看用户集合，用户关闭时计数减 1，归零时自动停止拉流，避免无人观看时持续消耗带宽。支持视频矩阵多屏同时监控。
        \end{itemize}
    }
    \cvlabeled{性能优化}{%

            \item 日志深分页：针对 30w 条日志的深分页瓶颈，通过延迟关联 + 覆盖索引优化，查询响应从 5s 降至 1s 以内，性能提升 5 倍

    \cvlabeled{项目地址}{%

    \cvlabeled{项目概述}{实现B站核心功能——用户体系、视频管理、弹幕系统、站内搜索，涵盖从注册登录、视频上传观看、弹幕实时推送到全文检索的完整闭环。}
    \cvlabeled{项目实现}{%
        \begin{itemize}
            \item \textbf{用户体系与安全}：基于工厂 + 策略模式构建登录系统（UserGranter 策略接口 + UserLoginFactory 配置驱动注册），新增登录方式只需实现接口并配置，无需修改调用方代码。基于 JWT 双 Token（access + refresh）实现无感登录，RSA 加密传输 + MD5 加盐存储保证密码安全。基于 RBAC + AOP 切面实现接口级和数据级权限控制，与业务代码解耦。

            \item \textbf{弹幕与动态推送}：基于 WebSocket 构建弹幕实时推送，后端异步消费 MQ 写入数据库实现削峰。基于 RocketMQ + Redis 订阅发布模式实现用户动态推送，减少 DB 直接压力。

            \item \textbf{视频存储与传输}：集成 FastDFS 实现视频分片上传、断点续传与秒传（文件指纹校验），通过 Nginx 提供外部 HTTP 访问。

            \item \textbf{性能优化}：自定义线程池（核心 5 线程、LinkedBlockingQueue），利用线程池并行聚合多源数据，数据汇总接口响应从 150ms 降至 50ms，提升 67\%。
        \end{itemize}
    }
    \cvlabeled{项目产出}{独立完成前后端全栈开发，涵盖用户体系、视频管理、弹幕推送、站内搜索、动态推送等核心功能；GitHub 开源。}
